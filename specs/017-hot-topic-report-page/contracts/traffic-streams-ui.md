# Contract: 交通頁的兩條流（`pages/traffic/index.html`、`pages/shared/app.js`、`pages/shared/shared.css`）

最終的字樣、位置、顏色與並排的寬度斷點以 Luke 簽核的畫面為準（FR-014、FR-002）。2026-11-04 簽核：截圖在 `../signoff/2026-11-04-*.jpg`，
下面標「簽核」的是那次定下的視覺；其餘是行為。

## 版面

| 寬度 | 顯示 | 切換 |
|---|---|---|
| 小於 1024 px（簽核） | 一次一條：目前那一條 | 頁首下方的兩個切換鈕「🔥 熱點」「📰 新文章」，等寬並排成一組；目前那一條是選取狀態（`--accent` 底、白字） |
| 1024 px 以上（簽核） | 兩條並排，熱點在左、新文章在右，各自有標頭（「🔥 熱點報告」「📰 新文章」）、導覽與捲動 | 不顯示 |

- 頁首照舊（標題、主題切換、FFXIV 與 RSS 連結），主題切換右邊多一個齒輪鈕（`#stream-settings-btn`，樣式同主題切換）。
- 並排時頁首與兩欄放寬到同一個最大寬度，兩欄等寬；1024 px 時各約 480 px，文章列是窄形（簽核接受）。
- 熱點那一條不出現在任何週次底下；新文章那一條沒有熱點區塊（FR-001）。

## 熱點那一條

- 批次導覽：每一批一個按鈕（例「11-02 · 2 份」），新的在前，預設最新一批；切批次只動這一條。按鈕樣式同週次導覽，
  但排成**一列、左右捲動**，不折行（簽核：412 px 下折行會有 8 行，把第一張卡片推到畫面中段）。新文章那一條的週次導覽照舊折行。
- 卡片：meta 列依序是「🔥 熱點」、所屬週報「11-02 週報」（簽核；`week_start_date` 的月-日，放在細框小標籤裡，不寫「產生」——手動 dispatch
  會在別天產生）、「📰 N 篇來源 · M 個媒體」與 LINE 分享；標題；焦點事件；報告內文（照現在的三軸呈現）。
- 焦點事件：有摘要的項目是按鈕（`.ht-focus-toggle`，`aria-expanded`），標題後面一個 ▸（展開時 ▾）；點標題就地展開「摘要＋閱讀原文 →」，
  展開區是淡底、左側 `--accent2` 色條的方塊；再點收合；預設收合。沒有摘要的項目是一般連結、不帶 ▸（FR-010）。編號對齊標題第一行（簽核）。
  摘要是報告資料裡存的那段（產生報告時截在 200 字，`src/analyzer.py`），可能停在句子中間；Luke 2026-11-04 接受，不補「…」。
- LINE 分享的網址是 `?batch=<week_start_date>#report-<slug>`（FR-015）。
- 報告清單載入失敗：這一條顯示「熱點報告載入失敗，請稍後再試」；新文章那一條照常。

## 新文章那一條

- 搜尋、週次導覽、標籤列、統計、分組列表都照現在，只屬於這一條。
- 切到一個週次時載入那一週的**全部**文章（逐頁，每頁 100 篇），不是前 100 篇；任何一頁失敗就照現在顯示載入失敗（FR-016）。
- 文章列沒有 ★，也沒有 `tr-strong`（FR-008）。

## 「有新的」標記（badge）

| 條件 | 熱點 | 新文章 |
|---|---|---|
| 基準之後有新的 | 「新 N」（例「新 2」） | 篇數（不含讀者收起的來源，與頁面統計一致）；超出 8 週掃描上限時是「N+」 |
| 沒有新的、第一次打開、或篇數還沒數完／數失敗 | 不顯示 | 不顯示 |

- 樣子（簽核）：紅色小圓角標，`--high` 底；亮色白字、暗色深字（同 `.imp-高`），緊接在切換鈕或標頭文字後面。
- 窄螢幕：badge 在切換鈕上；讀者從那一條切走時清掉（spec FR-004 的「看過」）。寬螢幕：badge 在那一條的標頭上，這次造訪裡一直顯示，下次打開重算。
- 基準與更新時機見 `local-state.md` 與 `data-model.md` 的狀態轉換。

## 齒輪設定

- 點齒輪打開一個小面板（簽核）：從頁首右下緣往下展開、蓋在內容上；標題「打開時先看」與右上角 ✕；三個單選項「預設（記得上次）」
  「🔥 熱點」「📰 新文章」，目前的選擇是 ● 加框加底、其餘 ○；最下面一行小字「只存在這台裝置。」。選了立刻存；點 ✕、再點齒輪或點面板外面都會關閉。
- 寬螢幕兩條都顯示，設定只影響窄螢幕的落地；面板照樣可用。

## 網址

| 網址 | 結果 |
|---|---|
| 沒有參數 | 照 `landingStream` 落地 |
| `?batch=<日期>#report-<slug>`，對得到報告 | 熱點、那一批、捲到那張卡片（不論設定） |
| `?batch=…` 對不到 | 照 `landingStream` 的其餘規則落地，不報錯 |
| 舊格式 `?week=<ISO 週>#topic-<slug>` | 新文章那一條選那個週次（現在的行為）；落地照 `landingStream`；`#topic-` 不處理 |
