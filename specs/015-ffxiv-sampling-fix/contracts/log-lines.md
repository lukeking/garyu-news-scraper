# Contract: 新增與改動的 log 行

讀者：週驗收 routine（`routines/weekly-verify/`，讀週報 log）與人工判讀。格式是契約，有讀者的那幾行用 unit test 鎖住。

## 有讀者、測試鎖格式

| 行 | 何時 | 格式 | 對應 |
|---|---|---|---|
| 候選池 | 每次 FFXIV 篩選 | `FFXIV 候選池 N 篇：<來源> a、<來源> b、…`（依篇數降冪） | FR-010、SC-006 |
| 入選 | 每次 FFXIV 篩選 | `FFXIV 入選 M 篇：<來源> a、<來源> b、…`（依篇數降冪） | FR-010、SC-001 |
| 解析出 0 項 | html_patch／html_forum／PTT 回 200 但 selector 對到 0 | `<來源>: 回 200 但解析出 0 項（selector 可能失效）`，並列入 `來源失敗` | FR-007、SC-004 |
| Lodestone 收進 | 每次收集 | `<來源>: 解析 N 則、收進 M 則（窗口外 a、排除 b）` | FR-006、SC-002 |

## 只給人看（不鎖格式，但每一種都要分得開）

| 行 | 何時 |
|---|---|
| `<來源>: <串標題前 30 字> 窗口內 N 則、收 M 則、翻 P 頁` | 每串 |
| `<來源>: <串> 翻到上限 P 頁仍未到窗口起點，可能還有更早的回覆沒收` | 翻頁上限 |
| `<來源>: <串> 討論串頁面請求失敗（<例外>），退回 RSS 最後一則` | 退回 |
| `<來源>: <串> 頁面解析不到回覆，退回 RSS 最後一則` | 退回 |
| `<來源>: <串> 回覆時間解析不出來（<原文>），退回 RSS 最後一則` | 退回 |
| `<來源>: 回滿 15 串且最舊一串仍在窗口內，可能有串被截掉（最舊 <時間>）` | 截斷 |
| `<來源>: 未設 weight，排在最後` | 每次收集，每個來源一次 |
| `跨週去重略過標題指紋（以回覆去重）：<標題前 50 字>` | 論壇項目過 `freshness_filter` |
| `<來源>: <標題> 詳細頁抓不到（<原因>），只用標題` | Lodestone 退回 |
